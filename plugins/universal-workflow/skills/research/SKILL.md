# Research

1. Establish the question and what the findings need to inform. Pull scope and constraints from the user's request and existing materials. Ask only when an unresolved ambiguity would materially change the investigation.
2. Find the source closest to each material claim. Use original records, direct observations, firsthand accounts, authoritative datasets, or official materials as the question warrants. Use secondary sources to find or contextualize evidence. Compare sources when they disagree and say when direct evidence is unavailable.
3. For substantial reading that can proceed independently, use a fresh background agent when delegation is available and permitted. Give it the question, source standard, and output location. Advance independent work meanwhile. Check that its sources support the consequential claims before handing off the result.
4. Produce one research brief with the question, findings, material limitations, and open questions that could affect the next decision. Cite material factual claims where they appear and mark inferences as such. Use the requested format and destination. Otherwise, save a standalone Markdown brief in the project's usual notes location, or answer inline if there is no project or requested file.

Finish when the brief answers the question to the extent the evidence supports and a reader can trace the findings back to their sources.
